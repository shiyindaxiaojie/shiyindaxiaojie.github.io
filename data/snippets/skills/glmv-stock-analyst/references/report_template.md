# report.md 完整模板与写作规则

**使用方式：** 每次写 report.md 前，先读取本文件，按模板结构填充内容。

**写作目标：** 先给用户能执行的结论，再展示证据。报告可以详细，但第一屏必须让用户看懂：现在能不能买、什么价位买、谁在买卖、有没有砸盘风险。

## 写作规则

1. **结论放在报告最前面** — 第一章必须给出可执行动作，不要从技术图开始。
2. **每个判断都有事实支撑** — 不说空话，每条观点都有数据/事件来源
3. **证据和判断物理分隔** — 用分隔线 `*═══ 以上是证据... ═══*`
4. **只保留强相关信息** — 不要无关新闻、其他个股研报、泛宏观
5. **用自己的话总结** — 不要堆砌原始数据
6. **"翻转条件"是必填项** — 明确什么信号会改变判断
7. **免责声明只在末尾一次**
8. **不编造数据** — 没获取到就说"暂无数据"
9. **席位身份要谨慎** — 只能写公开数据能确认的机构、沪深股通、营业部名称；不能把营业部直接断言为某个真实个人或隐藏主力。
10. **游资背景必须有来源** — 公开资料明确标注的知名游资席位才写背景；否则写"背景未公开/疑似短线资金"。
11. **动机是推断，不是事实** — 必须使用"更像/可能/疑似/置信度"表达，并写出支撑证据。
12. **讲人话** — 每个专业判断后都要补一句普通解释：这对买入、卖出、持仓意味着什么。
13. **市场投资情况必须单列** — 对外投资、并购重组、产业基金、监管问询、异常波动公告不能只塞进时间线，必须写投资标的、资金来源、对公司影响和公告后市场反应。
14. **表格不要挤成竖排** — 避免 6 列以上宽表；长文本字段改用表格下方的项目符号或短段落说明，席位表优先使用"类型/席位、买卖金额、行为判断、置信度"四列。

## 砸盘/洗盘判断口径

| 结论 | 必要证据 | 表述方式 |
|---|---|---|
| 游资砸盘 | 短线席位/营业部在卖榜靠前 + 高位放量回落/炸板 + 净卖金额较大 | "更像游资高位兑现，置信度X" |
| 主力出货 | 主力/超大单连续净流出 + 跌破关键支撑 + 反弹无量 | "更像大资金撤退，置信度X" |
| 洗盘换手 | 放量分歧但支撑未破 + 买榜有承接 + 次日/盘中修复 | "更像换手洗盘，置信度X" |
| 数据不足 | 无龙虎榜、无席位、资金流缺失或互相矛盾 | "公开数据不足，不能判断谁在砸盘" |

## 人话替换表

| 不要只写 | 要补成人话 |
|---|---|
| RSI 超买 | 涨得太急，追进去容易买在短线高点 |
| 主力净流出 | 大资金在卖，哪怕股价还涨，也说明风险在抬高 |
| 龙虎榜卖方集中 | 不是散户零碎卖，更像有明确资金在兑现 |
| 放量长上影 | 冲上去被砸下来，上方抛压重 |
| 缩量回踩 | 跌下来没有明显恐慌盘，可能只是正常换手 |
| 跌破 MA20 | 中短线趋势支撑坏了，不能再按强势股看 |
