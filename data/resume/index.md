# GitOps + OAM Delivery
<!-- layout: flow -->
> With Jenkins, CODING, and KubeVela as anchors, teams can release applications inside standard boundaries. Delivery becomes orchestrated, auditable, and rollback-ready.

## Delivery Path
<!-- kind: steps -->
- Template Abstraction :: Operations teams maintain component templates and plugins, so developers do not work directly with Deployment, Service, ConfigMap, and similar details.
- Application Composition :: The App becomes the delivery unit for environments, configuration, dependencies, and versions, shifting delivery from resources to applications.
- Self-service Release :: Developers select versions, publish to environments, and switch gray releases inside permission boundaries, reducing manual release dependency.
- Rollback and Audit :: Build, deployment, alerting, and rollback records are kept end to end for production delivery and compliance.
