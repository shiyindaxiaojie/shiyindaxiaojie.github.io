::interviewer::
挑一个最能体现 Python 工程能力的项目，先讲它解决了什么问题。

::candidate level="core"::
先讲业务或自动化链路，再说明自己负责的数据、接口和运行边界。Python 的价值可能是生态、开发效率或数据处理，但结果要落到交付、稳定性或维护成本，不能把“开发快”当作未经验证的结论。

::interviewer::
这段回答怎么用真实材料支撑，而不是只靠口述？

::candidate level="deep"::
用代码与接口边界、发布记录、性能 profile、故障和真实结果指标证明项目深度，不编造个人经历数据。

::interviewer::
Python 经历这段经历还有什么代价或没解决的问题？

::candidate::
Python 原型很快，但依赖、类型和运行时行为若不治理，会把成本推到生产。项目价值要包含后续维护。
